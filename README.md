# Bibata Caelestia

A dynamic Material You themeable cursor theme based on **Bibata Modern Classic**, designed for [`caelestia-cli`](https://github.com/dim-ghub/caelestia-cli).

Automatically matches your current Caelestia wallpaper/scheme colors and reloads live across Hyprland, XWayland, GTK, and Sober (Roblox).

## Setup

Run the installer:

```bash
./install.sh
```

The script will prompt for your preferred cursor size, set up Caelestia templates, configure post-hooks, and build the initial theme.
